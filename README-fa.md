# کلید — نسخه اولیه

اپی فارسی برای دسترسی سریع به سایت‌های پرکاربرد. این نسخه با Vite و Capacitor ساخته می‌شود و workflow گیت‌هاب می‌تواند APK آزمایشی بسازد.

## ساخت APK بدون نصب Android Studio روی کامپیوتر

1. یک حساب GitHub بساز یا وارد [github.com](https://github.com) شو.
2. یک repository جدید با نام `kelid` بساز.
3. محتویات این پوشه را در repository بارگذاری کن (Upload files) و commit کن.
4. وارد تب **Actions** شو و workflow با نام **Build Android APK** را انتخاب کن.
5. روی **Run workflow** بزن (یا پس از push، اجرای خودکار را باز کن).
6. وقتی سبز شد، اجرای workflow را باز کن و از بخش **Artifacts** فایل `kelid-debug-apk` را دانلود کن.
7. فایل ZIP دانلودشده را باز کن و `app-debug.apk` را به گوشی منتقل و نصب کن. ممکن است لازم باشد اجازه نصب از این منبع را فعال کنی.

## اجرای محلی برای توسعه

نیازمند Node.js 20 یا بالاتر و Android SDK/JDK مناسب برای ساخت اندروید است.

```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

## نکته‌های مهم

- این خروجی debug APK برای آزمایش و نصب شخصی است، نه انتشار رسمی فروشگاهی.
- دکمه‌های سایت‌ها از مرورگر درون‌برنامه‌ای اندروید استفاده می‌کنند. این موضوع به سازگاری ورود و سیاست امنیتی هر سایت بستگی دارد؛ بعضی سایت‌ها ممکن است به مرورگر کامل یا تأیید پیامکی نیاز داشته باشند.
- آدرس‌های سایت‌ها در `src/main.js` تعریف شده‌اند و ممکن است تغییر کنند. قبل از انتشار، لینک‌ها را بررسی کن.
- لوگوها فعلاً ایموجی هستند تا نسخه اولیه سبک بماند. می‌توانیم در مرحله بعد آیکن‌های رسمی و صفحه علاقه‌مندی‌ها را اضافه کنیم.
